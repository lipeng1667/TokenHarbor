少输入与项目归集如何兼顾

普通 API 即可记录每次调用；平台管理自身发起的任务与尝试。有可靠任务、批次或明确配置的项目关联时，才合并项目费用。共用 API Key 或相似提示词不能证明属于同一项目，缺少信息时保留待归属。基础追踪拟不单列收费；项目利润还需结合收入、人力等其他成本。
