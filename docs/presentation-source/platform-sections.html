TokenHarbor 产品规划

让 AI 调用的成本与交付更清晰

TokenHarbor

多模型统一 API 与按量计费平台

把不同供应商的能力接入、执行状态和用量管理连起来，帮助客户减少集成与维护工作，并用实际数据检验优化收益。

01

统一能力接入

面向文本、图片与视频，提供明确的能力接口和交付方式。

02

透明计量与交付

追踪每次真实调用，关联任务状态、供应商用量与结算依据。

03

持续优化成本

在约定的模型、质量和时延要求内，识别并验证可减少的开销。

当前为产品与技术规划，尚未形成已上线的业务实现或生产计费能力。以下描述的是目标设计与验证路径。

TokenHarbor 技术规划

分层处理接入决策与执行

职责清楚

Portal 管理客户连接，Kernel 协调规则与状态，Dispatcher 处理供应商协议。Nginx 不决定余额或业务扣费。

持久化支撑

任务、用量证据、价格版本、预占和账本统一关联，恢复与通知具备可追溯依据。

独立运营后台

配置、报表与审计由独立后台提供，核心调用不依赖管理页面是否在线。

技术选型待验证

核心倾向 C + libevent，PostgreSQL 为建议持久化方案。进程划分、内部通信和响应数据路径通过原型确定。

TokenHarbor 接入体验

少做非必要的数据维护

基础管理不要求客户额外填写业务任务编号。

  1. 01

    正常发起请求

    客户提供凭证、模型与请求内容，保持原有调用习惯。

  2. 02

    平台自动关联

    生成技术标识，关联请求、异步任务、供应商尝试、用量和费用。

  3. 03

    管理状态与优化

    提供查询与异常解释，在可观测范围内识别优化机会。

可选 SDK 封装

在首次发送前生成幂等键，重试时自动复用，并封装任务查询与结果接收。

必要意图再确认

换模型、压缩正文或延后交付可能改变结果，需要客户约定，不能仅凭平台推断。

基础技术追踪与管理默认包含拟不单列收费，模型调用与约定的增值费用按相应规则计收。

相同输入也可能代表客户主动再次生成。平台自动编号和分析分组不直接作为语义去重、扣费或拼接客户上下文的依据。

技术亮点一

每笔成本都有可追溯依据

把一次调用的所有尝试与最终费用放在同一条证据链上。

用量

Token、张数、时长等按真实计量规则记录，缺失用量不补零。

成本

覆盖所有供应商尝试与额外处理开销，未知费用明确标记。

价格

记录客户适用的计价版本，使费用能够复算。

账本

关联预占、结算、释放与后续调整，避免重复结算。

执行未知先核对

网络超时不能证明生成未发生。确认未发送或具备已验证的幂等保证后，才在总预算内安排重试。

拟议验收指标证据覆盖率、对账差异、未确认成本占比、重复结算情况

17

技术亮点二

用实际效果选择优化策略

先观察，再验证。在客户约定的能力和交付要求内逐步调整。

  1. 01

    观察调用特征

    稳定前缀、缓存命中、输入规模、时延、错误及真实费用。

  2. 02

    形成候选策略

    缓存参数、适用渠道、连接与配额调度、异步查询与恢复。

  3. 03

    验证与回滚

    建立基线，进行小流量验证，保留有效策略并撤回无收益策略。

优先保持模型与内容

先验证缓存和执行效率的收益。前缀缓存依赖实际命中，不能预先把全部输入算成缓存价。

内容处理按需启用

摘要、裁剪、检索、模型替换和延迟交付，需要约定和评测。减少 Token 不必然降低总成本。

拟议验收指标实际净节省、成功交付率、约定质量指标、P95 时延

18

技术亮点三

让长任务与异常交付有据可查

客户连接、内容生成、账务和通知分别管理，避免把一种失败误判为全部失败。

文本流式交付

通常通过 SSE 返回生成内容，管理慢连接、缓冲与断线状态。

图片与视频任务

持久化任务与结果，按供应商能力通过查询或回调获得更新。

通知可靠投递

重复投递同一通知不触发再次生成，也不因此增加生成费用。

断线不等于供应商取消成功。结果重放受留存与协议约定限制，不承诺跨供应商网络绝对只执行一次。

TokenHarbor 效果验证

相同价格下比较完整成本

使用同一任务集和验收口径，同时观察质量、成功率与时延。

A

客户当前直连

纳入客户已有缓存和重试策略，建立当前使用基线。

B

通过 TokenHarbor

统计平台方案的效果，包含平台费用与额外处理费用。

C

直连做同等优化

检查成熟客户采用相同策略后，平台还提供多少增量价值。

完整费用口径

全部模型调用费用包含缓存、摘要与重试+其他处理费用+平台费用

费用项目互不重复，额外检索、评测和回退均应计入。只有在验收通过的任务数量相同、质量与时延达标时，才以两组完整费用之差衡量净节省。

若客户直连已做到相同优化，平台不天然具有调用成本优势。其价值还需要结合集成、维护和排障工作衡量。

有明确业务验收时，同步计算单位成功任务成本：完整费用 ÷ 验收通过任务数。没有业务验收反馈时，仅报告技术交付指标。以上为拟议验证方法，并非已完成的降本实验。
