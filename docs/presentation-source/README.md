# 官网交流页面源文件

两份交付仍使用原路径：

- `../team-background.html`：团队技术背景，7 个内容章节。
- `../tokenharbor-presentation.html`：团队背景与 TokenHarbor 规划，共 14 个内容章节。

页面为连续滚动的原生 HTML，不使用整页截图或幻灯片画布。标题、正文、数据说明、表格和架构节点可选择、搜索与替换；原 PPT 的地图、客户标识、产品截图及必要图形保留为独立素材。桌面多列内容在手机端重新排列，文字保持正常阅读字号。

在项目根目录执行：

```sh
python3 scripts/build-presentations.py
```

修改上述 HTML 片段即可更新文案。历史架构使用普通 HTML 元素；TokenHarbor 的客户入口、项目成本场景、分层架构、账单、计算复用对照、恢复时间线和验证流程采用 `.th-*`、`.thv-*` 专用 HTML/CSS 与少量无文字 SVG 连线。节点、标签和数字均可直接编辑；平台图示样式仅作用于平台章节，共用字体规则覆盖两份页面。Portal、Kernel、Dispatcher 分别使用入口、协调中枢、分发分支三种原创 SVG 图标。图片在源片段中使用 `src="media/文件名"`，构建时自动内嵌为 data URL，保留 `data-source` 来源属性。更新素材后重新构建即可。生成脚本仅依赖 Python 标准库。

## 字体与文字层级

`typography.css` 统一定义无衬线字体栈：PingFang SC → Microsoft YaHei → Noto Sans CJK SC / Noto Sans SC → 系统 sans-serif。中文、英文和数字使用同一规则；不再为标题使用宋体、为序号使用 Georgia，也不下载外部字体。各设备使用本地可用的首选字体，字形可能随系统变化。

字重限制为 400（普通文字）、500（标签和指标）、600（标题和强调）。章节标题统一为桌面 36px、手机 28px，正文主要为 16px，说明为 12–14px，小标题使用 20/24/28px 等公共层级；封面与重点数字保留更大的展示尺度。标题行高 1.4，紧凑标签 1.5，正文 1.75，数字 1.2；符号保留独立行高。长数字保留响应式字号和等宽数字设置，OES 等图内文字保留随容器缩放的字号。

字体统一轮次仅调整文字样式；后续样式精简轮次保留核心内容、图片与图表数值/比例，布局变更见下文。手机标题优先按已有空格分句；过长内容仍允许换行。原截图和标识内的文字保留原图。

## 使用与官网接入

生成的 HTML 内含图片、样式与少量增强脚本，可直接在本地浏览器打开。禁用 JavaScript 时，正文、表格、架构与原生目录锚点仍可阅读使用。页面不加载外部字体、图片或分析脚本，也不依赖本地 PPT、PDF 或项目规划文档。

完整版已发布至[申行科技官网固定地址](https://shenxingkeji.cn/assets/presentations/tokenharbor.html)。发布使用官网现有流程，源文件、构建产物与公网正文的 SHA256 一致；具体版本与验收结果见 `publication.md`。固定路径配置重新验证缓存，后续更新沿用相同地址；版本化文件保留作为归档，不覆盖旧文件。页首品牌为文字“申行科技”，没有自造 Logo、联系方式或官网域名。

## 内容口径

团队部分按最新确认精简为七章：QoS 与防骚扰合并；移除商城、智能服务云、集中短信架构三个独立章节；MaaP 在 OES 前，OES 为历史部分末章。短信与号码认证为用户确认由团队搭建的重点产品，两页以原项目历史数字为主要内容。

短信保留伙伴地图，展示 34／260／1397 亿条三条发送记录，以“平台上线／次年／第 3 年”表达，用户确认 34 亿条属于上线当年，原稿未标明上线时间，1397 亿条原文为“至今发送量”，前两条未明确年度或累计口径，不计算年度增幅。主成果卡为日均 600,000,000 条、日最高 1,000,000,000 条、累计接入 8,000+ 家用户（原稿 8,209 家的简写），附一点接入、3 大运营商、7 种协议短条。原稿 200 亿预计收益不列为实绩。

取号展示近 6,000 家 APP、每天超 20 亿次及支持 5G 套餐用户；以可读的密码、短信和运营商取号机制说明替代原稿定性评分，不对竞争方式作无依据的优劣判断。技术内容保留 App / Web 接入、IPv4 / IPv6 地址处理、4G / 5G 路径分流三项短条；NIS 的完整机制、文件定位和边界保留在 `project-evidence.md` 维护档案。

行业量收变化、全国用户规模、现行运营商 SDK 介绍及行业市场预测不作为项目成果。历史数字通过简短标题和标签标明历史范围及统计口径，来源细节留在维护档案；页面不显示绝对年份，原年份映射只留在维护说明。客户标识与产品截图并非当前客户背书。TokenHarbor 第 08–13 章依次展示客户价值与成本场景、明星项目与 OES 基础的过渡、概念架构和三项技术亮点。第 14 章实施路线已按用户要求删除；费用记录规则默认展开。团队工程经验与 TokenHarbor 平台规划分开表达，项目费用仅在可靠关联下归集，费用待核与待归属分开；不展示未经验证的吞吐或节省比例。顶部位置提示由实际章节列表更新，完整页 13 章、团队页 7 章；目录点击、滚动与窗口尺寸变化同步当前位置。详细依据见 `platform-evidence.md`。

原始 PPT/PDF、`original/`、`background.svg` 和 `background-architecture.svg` 仅保留本地，用于内部追溯，**不随此次提交，当前构建也不需要这些资料**。原始资料与既有项目规划未改写。
