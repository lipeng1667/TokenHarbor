# 官网交流页面源文件

两份交付仍使用原路径：

- `../team-background.html`：团队技术背景，11 个内容章节。
- `../tokenharbor-presentation.html`：团队背景与 TokenHarbor 规划，共 21 个内容章节。

页面为连续滚动的原生 HTML，不使用整页截图或幻灯片画布。标题、正文、数据说明、表格和架构节点可选择、搜索与替换；原 PPT 的地图、客户标识、产品截图及必要图形保留为独立素材。桌面多列内容在手机端重新排列，文字保持正常阅读字号。

## 内容维护

| 文件 | 作用 |
| --- | --- |
| `team-sections.html` | 团队背景 11 章的正文、表格与架构节点 |
| `platform-sections.html` | TokenHarbor 10 章的产品与技术规划 |
| `viewer.css` | 排版、流程图、响应式与打印样式 |
| `viewer.js` | 目录关闭、当前位置提示与打印按钮增强 |
| `media/` | 从原 PPT 提取的独立图片、局部图形及来源清单 |
| `../../scripts/build-presentations.py` | 组装品牌页首、目录和正文，生成两个单文件 HTML |
| `content-notes.md` | 内部来源、改写口径与待确认事项，不嵌入对外页面 |

在项目根目录执行：

```sh
python3 scripts/build-presentations.py
```

修改上述 HTML 片段即可更新文案。架构图使用 `.node`、`.flow-column`、`.flow-row`、`.branch-grid` 等普通 HTML 元素，布局由 CSS 负责。图片在源片段中使用 `src="media/文件名"`，构建时自动内嵌为 data URL，保留 `data-source` 来源属性。更新素材后重新构建即可。生成脚本仅依赖 Python 标准库。

## 使用与官网接入

生成的 HTML 内含图片、样式与少量增强脚本，可直接在本地浏览器打开。禁用 JavaScript 时，正文、表格、架构与原生目录锚点仍可阅读使用。页面不加载外部字体、图片或分析脚本，也不依赖本地 PPT、PDF 或项目规划文档。

正式网址、官网模板与发布流程尚未指定，本次仅生成并验证本地文件，没有部署。后续可以将选定 HTML 放入指定静态路径，也可把正文片段和 CSS 接入现有官网模板。页首品牌为文字“申行科技”，没有自造 Logo、联系方式或官网域名。

## 内容口径

团队部分按原稿逐页恢复。旧公司称谓改为“原项目团队”等中性表述，不能把旧业绩换名归给申行科技。原图需要的年份、业务规模和预测予以保留，并明确历史期间及未核实口径，不补造新年份、当前业绩或性能。客户标识与产品截图属于原稿历史展示，并非当前客户背书。TokenHarbor 相关能力继续标明规划状态。

原始 PPT/PDF、`original/`、`background.svg` 和 `background-architecture.svg` 仅保留本地，用于内部追溯，**不随此次提交，当前构建也不需要这些资料**。原始资料与既有项目规划未改写。
