# 核心项目历史成果、技术依据与证据边界

核对日期：2026-11-05。用于维护短信、号码认证两章。只记录抽象机制、文件定位与版本；不复制私有源码、生产地址、凭据、真实用户数据或完整部署配置。

## 内容主线

用户确认短信和取号两个平台均由团队搭建。对外页面明确团队建设贡献，以原项目历史规模数字为主，配合简短技术能力。全国行业量、全国移动用户数、现行运营商 SDK 和行业市场预测不用于证明团队成果。

页面保留历史短信地图、伙伴标识、发送记录及原项目接入范围；取号展示历史使用规模、5G 套餐用户支持与原稿四行定性比较表。详细调用机制和源码定位保留在本档案，不作为两页的主要视觉内容。历史数据不代表当前规模，定性比较不视为性能测评。

## 对 OES 验证的使用

另行阅读了 `tests/oes-linux/REPORT-2026-11-05.md` 与功能结果。它支持 OES 通用系统在指定现代 Linux、模拟下游与两笔合成订单条件下的构建及功能验证，包括同步调用、订单查询、重复拒绝、异步回调和账务写入。它不能证明真实短信发送、取号执行、生产吞吐或完整生产验收。

因此本轮没有把该验证写成两项核心产品的实测性能，也没有把历史签名/鉴权码实现扩大表述为现代强密码安全。OES 章维持原有内容，不借本次改稿增加生产承诺。

## 对外披露与未验证项

- 公共页面使用原稿历史数字、定性比较、简短技术能力及历史案例范围；不展示源码正文、实际 API 地址、签名样例、部署 IP、凭据和真实用户数据。
- 伙伴标识为原项目背景，不声明当前合作关系。短信中心、BSS 等明确为运营商系统对接范围。
- 当前吞吐、峰值、成功率、可用性、接入企业数和业务收入没有新的同口径运行证据，不编造数字或将全国数据挪作项目业绩。
- “近 6000 家 APP／每天超 20 亿次”按原稿限定词和历史口径展示，不视为最新运营证据。原取号架构综述及市场预测不用于收入或规模推算，原稿定性比较也不用于宣称现行安全或成本优势。
