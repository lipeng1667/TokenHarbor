QoS 与防骚扰的六张图保留在同一章；商城、智能服务云和集中短信整体架构三个独立章节保持删除。短信章以历史数字和接入范围展示，不重新增加被删除的架构章节。MaaP 在 OES 前，OES 为历史部分末章。

## 本轮修改的两章

- 短信：保留地图与伙伴标识，以 34／260／1397 亿条三条发送记录，以及日均 600,000,000 条、日最高 1,000,000,000 条、累计接入 8,000+ 家用户为主；“一点接入、3 大运营商、7 种协议”收为短条。
- 取号：以近 6000 家 APP、每天超 20 亿次、支持 5G 套餐用户为主，复原原稿用户体验、企业成本、接入难度、安全性四行圆形定性比较表。仅保留 App / Web 接入、IPv4 / IPv6 地址处理、4G / 5G 路径分流三项短技术能力，详细 NIS 依据留在维护档案，不再以大段工程问题或流程图组织两页。
- 两页均撤下行业下降、全国用户规模、现行运营商 SDK 介绍及大块待补数据提示。历史数字明确来自原项目，不用行业统计或市场预测填补团队业绩。
- OES 源码和隔离测试另有证据，但不将其模拟订单验证当作短信或取号生产性能。

原稿、文档、源码位置及精确边界见 `project-evidence.md`。上一轮公开资料研究保留于 `data-sources.md`，只作查证档案。该轮数字调整保持其余五章和 TokenHarbor 十章不变；随后平台改版范围见文末。

## 素材与维护

原 PPT、PDF 和整页转换档案仍只保留本地。`media/manifest.json` 记录独立素材的原页码、提取方式与哈希；原页码不随网页重排改变。原 PPT 与相关源代码仓库未修改。

历史七章的小标题统一为“团队历史项目”。对外页面删除页脚式免责声明与维护说明，必要口径改为可见的简短标题或标签：短信“历史发送量记录／第三年·累计”、取号“历史服务规模／原稿定性评价”、大数据“历史数据处理规模／历史服务”、OES“原稿性能”。图表旁的资料来源类小标题移除，详细来源映射和待核实内容只保留在维护档案。

页面仍连续滚动，标题、文字、数字、比较表和说明可编辑。图片用于原地图、标识、产品 UI 和必要图形。图内原始产品细字清晰度受素材限制。

## 未验证及对外范围

1. 当前生产吞吐、峰值、成功率、可用性、客户数量及收入需同口径运行证据；本次不补造最新数值。
2. 伙伴标识为历史项目背景，不作为当前客户背书；运营商下游网元不表述为全部由团队建设。
3. 源码复核属于实现证据，不等于生产运行或安全审计；配置式校验不写成所有请求的无条件保障。
4. 既有大数据、OES 历史性能以及 MaaP 口径沿用上一版边界。
5. 用户后续已明确授权发布官网；须使用已核实的官网部署流程，发布前后的版本与可访问性验收另行记录。
