# TokenHarbor

多家大模型统一 API 与按量计费平台，当前处于项目规划阶段。

## 项目文档

[打开团队背景与 TokenHarbor 技术方案](docs/tokenharbor-presentation.html)

[打开团队技术背景](docs/team-background.html)

两份文档均为面向申行科技企业交流的连续滚动 HTML，分别包含 17 个和 7 个内容章节。标题、正文、表格及架构节点均为原生 HTML，可搜索、复制与维护，手机端会重新排版。支持目录锚点和打印，单文件可离线打开。

历史项目部分包含行业背景、短信网关、号码认证、QoS 与防骚扰、大数据、MaaP、OES 七章，保留短信地图、伙伴标识和产品图片。短信与号码认证以原项目历史数字为主：短信展示 34／260／1397 亿条三条发送记录，以及日均 6 亿条、日最高 10 亿条、累计接入 8209 家用户；取号展示近 6000 家 APP、每天超 20 亿次及支持 5G 套餐用户，并复原原稿四项定性比较。页面使用相对年度，不把首个记录年度当作上线年，不计算口径未明的年度增幅，也不将收益预测列为实绩。数字不代表当前规模，比较图不是性能测评；简短技术能力与详细 NIS 依据分别保留在页面和[项目证据说明](docs/presentation-source/project-evidence.md)，不以行业统计替代团队成果。TokenHarbor 的客户价值、技术架构、最少输入的智能管理、三项技术亮点、收益验证与实施路径继续明确为规划方案。本次未部署到官网。

文案分别维护在 `docs/presentation-source/team-sections.html` 和 `platform-sections.html`，运行 `python3 scripts/build-presentations.py` 生成交付文件。完整维护方式见 [源文件说明](docs/presentation-source/README.md)。

[打开项目规划与技术设计（HTML）](docs/project-plan.html)

下载仓库后，用浏览器直接打开 `docs/project-plan.html`。文档可离线阅读，包含响应式目录、架构示意、异常处理矩阵和打印样式；无需安装依赖或启动服务。GitHub 文件页显示源码，浏览完整排版请下载后本地打开。

所有未确认的选型和商业规则均标为建议或待决策；金额算例不代表官方报价。技术来源和访问日期见文档末章。

当前仓库只包含规划文档，尚无业务实现、部署或生产计费能力。
